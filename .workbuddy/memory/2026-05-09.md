### 4. 结算明细表格
- 每个门店一张12行表格，包含：
  - 初始报价数据：初始报价金额、初始成本金额、初始利润
  - 增减项数据：增减项报价金额、增减项成本金额、增减项利润
  - 最终结算数据：最终对外报价金额、最终应支付结算金额、最终利润
  - 实际支付数据：首次结算支付金额、后续结算支付金额、未支付金额
- 10个费用列：工程硬装、广告物料、安装收尾、家具、灯具、配电箱、设计、空调、消防、其他工程类
- 自动计算公式（与Excel一致）
- 工程类费用小计 = SUM(10个费用列)
- 整体筹建费用总计 = 工程类费用小计 + 设备费用

### 5. 结算状态自动计算
- **单列状态**：最终应支付有值+首次支付=0 → 报价阶段；首次支付有值+未支付≠0 → 已付首款；最终应支付有值+未支付=0 → 已结算完成
- **门店总状态**：任一初始报价有值+所有首次支付=0 → 报价阶段；任一首次支付有值+任一未支付≠0 → 已支付部分款项；任一最终应支付有值+所有未支付=0 → 已结算完成
