### 41. 修复后端部署路径错误
- **问题**：GitHub Actions虽然显示成功，但后端修改角色API未生效
- **根因**：后端SCP步骤的`strip_components: 0`导致`backend/server.js`被复制到服务器的`/var/www/store-progress-manager/backend/backend/server.js`（多了一层backend目录），而pm2运行的是`/var/www/store-progress-manager/backend/server.js`（旧版本）
- **修复**：`strip_components: 0` → `strip_components: 1`，去掉source路径中的`backend/`前缀，使文件正确覆盖到目标位置
- **提交：** 88bb53f → GitHub Actions 自动部署中
